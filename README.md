## What Conversion Auditor Does

Conversion Auditor is an AI-assisted web utility for evaluating landing pages. It places landing-page analysis and conversion review in one browser-based workflow, giving users an automated way to examine how a page is presented.

The project is intended for marketers, designers, site owners, and others who build or maintain landing pages. Its web interface offers an additional perspective during page reviews and helps identify topics that may warrant closer consideration.
